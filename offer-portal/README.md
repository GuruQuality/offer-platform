# Offer Portal

SPA для платформы персональных офферов: отдельный вход для клиента и
маркетолога, витрина предложений и кабинет управления акциями.

> Полная инструкция запуска API и SPA — в [корневом README](../README.md).

## Стек

- React 19 + TypeScript
- Vite
- Чистый CSS, без UI-библиотек
- Только React Hooks и `useState`
- Сессия в `localStorage`
- Навигация без React Router — экран выбирается по роли пользователя

## Что реализовано

### Клиент

- Вход с доступами `user-123 / user-123`.
- Загрузка списка акций из API.
- Выбор акции и запрос персонального оффера.
- Карточка-купон с текстом предложения.
- Заглушка «Для вас пока нет активных предложений» для ответа `404`.
- Понятные состояния загрузки и ошибок без сырого JSON.

### Маркетолог

- Вход с доступами `admin / admin`.
- Создание акции: код, текст оффера.
- Обновление каталога после успешного создания.
- Список активных акций.
- Мини-форма проверки предложения от имени клиента.

### Общее

- Шапка с текущей ролью и кнопкой «Выйти».
- Сохранение сессии и кэша каталога в `localStorage`.
- Адаптивная вёрстка для desktop, tablet и mobile.
- Доступные поля, радиокнопки, фокус-состояния и `aria-live` для результатов.
- Технические названия полей API не выводятся в интерфейсе.

## Требования

- Node.js `^20.19.0` или `>=22.12.0`;
- npm;
- запущенный mock API на `http://127.0.0.1:8000`.

Все команды ниже выполняются из **корня проекта** — папки, в которой лежат
`mock-api/` и `offer-portal/`.

## Запуск

### 1. Запустить mock API

```bash
cd mock-api
./.venv/bin/python -m uvicorn app:app --reload --port 8000
```

API должен быть доступен на `http://127.0.0.1:8000`. Swagger:
`http://127.0.0.1:8000/docs`.

### 2. Установить зависимости SPA

```bash
cd offer-portal
npm install
```

`npm install` нужен только при первом запуске или после изменения
`package.json`.

### 3. Запустить frontend

```bash
cd offer-portal
npm run dev
```

Откройте: **http://127.0.0.1:5173**

Остановить Vite: `Ctrl+C` в терминале, где он запущен.

## Перезапуск

Вручную перезапускать Vite обычно не нужно — он сам обновляет страницу при
изменении кода. Перезапуск нужен после изменения `.env` или установки новых
пакетов:

1. В терминале с `npm run dev` нажмите `Ctrl+C`.
2. Выполните:

```bash
cd offer-portal
npm run dev
```

3. Дождитесь строки `Local: http://127.0.0.1:5173/`.

## Настройка адреса API

По умолчанию SPA обращается к `http://127.0.0.1:8000`. Если API работает на
этом адресе, создавать `.env` **не нужно**.

Если API запущен на другом адресе, из корня проекта:

```bash
cd offer-portal
cp .env.example .env
```

```env
VITE_API_URL=http://127.0.0.1:8000
```

После изменения `.env` перезапустите Vite.

| Маркетолог | `admin` | `admin` |

## Проверка production-сборки

```bash
cd offer-portal
npm run build
npm run preview
```

`npm run build` выполняет TypeScript-проверку и собирает приложение в `dist/`.

## API

Приложение использует:

- `GET /admin/offers`
- `POST /admin/offers`
- `POST /alpha/request`

Mock API хранит каталог акций в памяти: после перезапуска сервера добавляются
только три стартовые акции. CORS для локальных адресов `localhost` и
`127.0.0.1` уже настроен на стороне mock API.
